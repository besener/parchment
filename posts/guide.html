HTML 101 Guide: How To Start

August 24, 2025

I'm a self-taught HTML coder, and I really enjoy using GitHub. It's a great place for open-source projects, where you can contribute, learn from others, and build your skills by working with different codebases. Reading markdown guides and README files has helped me learn some basic HTML and pick up a bit of JSON and CSS as well. There are also many how-to videos available to watch and learn more.

With that in mind, I built my blog, Parchment, from the ground up using HTML, JSON, and CSS in my GitHub repository, and published it with Hugo. As an educator, I also received a free GitHub Pro badge, which connects me to the GitHub Education community and gives me access to tools like GitHub Copilot.

GitHub has some helpful features, such as Code Review, which allows you to submit pull requests for your team to review and provide feedback directly within the code. Another useful feature is Codespaces, which makes it easy to work on your projects from any device with an internet connection.

Although my background is in art history and I have never taken a programming course, my curiosity for coding has always been strong. After teaching myself the basics of HTML, I decided to craft an HTML 101 Guide that highlights essential codes and invites fellow beginners to jump in and start experimenting.

🕮 What is HTML?

  • HTML = HyperText Markup Language
  • HyperText → clickable links to other pages or sites
  • Markup Language → special tags that describe how content should be structured

🕮 The Building Blocks

  • Tags: keywords inside < > 
    <h1>Title</h1>
  • Element: opening tag + content + closing tag 
    <p>This is a paragraph.</p>
  • Attributes: extra details inside an opening tag 
    <img src="dog.jpg" alt="A happy dog">

🕮 Common Tags

TagWhat it doesExample
<h1> … <h6>Headings (biggest → smallest)<h1>Main Title</h1>
<p>Paragraph<p>Text here.</p>
<a href="">Link<a href="https://example.com">Click me</a>
<img>Image<img src="cat.jpg" alt="A cat">
<ul> / <ol>Lists (unordered / ordered)<ul><li>Item</li></ul>
<li>List item<li>Step 1</li>

🕮 Page Skeleton

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>Welcome to my webpage.</p>
  </body>
</html>

🕮 Some Tools You Can Use

  • Any text editor: Notepad, TextEdit, Typora, etc.
  • Code editors: Visual Studio Code, Sublime Text, Atom
  • Online editors: CodePen, JSFiddle, or your class Canvas HTML editor

✅ Tip: HTML is about structure, CSS handles style, and JavaScript adds interaction.
