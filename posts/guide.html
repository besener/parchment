What is Hypertext Markup Language (HTML)?

HTML stands for Hypertext Markup Language. It's the main tool for building and organizing webpage content. You can think of HTML as the skeleton of a website, shaping everything you see online. With HTML, you use ‘tags’ and ‘attributes’ to add headings, paragraphs, images, and links.

  • HTML = HyperText Markup Language
  • HyperText → clickable links to other pages or sites
  • Markup Language → special tags that describe how content should be structured

An HTML text has a basic structure to begin:

  • <!DOCTYPE html> : This defines the document to be HTML5.
  • <html> : This is the root element of an HTML document.
  • <header> : This contains introductory content or navigational links.
  • <nav> : This is for navigation menus.
  • <body> : This contains the visible page content that is displayed in the browser window.
  • <article> : This is a self-contained piece of content, such as a blog post (which I use frequently).
  • <section> : This is for grouping related content.
  • <aside> : This is for content related to the main content, such as a sidebar.
  • <video> and/or <audio> : This is for embedding audiovisual multimedia into your page without requiring third-party plug-ins.

What is HTML5?

HTML5 is the latest version of Hypertext Markup Language, introducing new features and a more structured approach to web content. This version also helps search engines and assistive technologies, such as screen readers, to easily navigate and interpret the structure or layout of a webpage. HTML5 creates a smoother and more intuitive user experience, reducing the need for JavaScript in basic coding.

The Building Blocks of a Webpage

HTML uses elements to organize your content. These elements decide how things appear and function on a webpage. For example, to create a paragraph, you place your text inside a <p> tag. Headings use ‘tags’ like <h1> or <h2>, where <h1> is the largest and most important.

For example:

  • Tags: keywords inside < > 
    <h1>Title</h1>
  • Element: opening tag + content + closing tag 
    <p>This is a paragraph.</p>
  • Attributes: extra details inside an opening tag 
    <img src="dog.jpg" alt="A happy dog">

Sample Page Structure

<!DOCTYPE html>
<html>
  <head>
    <title>My First Webpage</title>
  </head>
  <body>
        
    <article>
     <h1>This is a heading. Hello, world!</h1>
     <p>This is a paragraph text. Welcome to my page.</p>
    </article>

  </body>
</html>

Some Tools You Can Use

    You can start with an online editor to practice HTML, CSS, and JS structures quickly:

  • Online editors: CodePen, JSFiddle, or your class Canvas HTML editor

    • Code editors are good for syntax highlighting, auto-completion or code suggestion, and preview:

  • Code editors: Visual Studio Code, Sublime Text, Atom

    • You can use simple code-writing editors to encourage yourself to learn basic HTML structure:

  • Text editors: Notepad, TextEdit, Typora

✅ Tip: HTML is about structure, CSS handles style, and JavaScript adds interaction.
